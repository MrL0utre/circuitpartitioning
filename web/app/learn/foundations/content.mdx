# Definitions and objectives for circuit partitioning

Circuit partitioning assigns the elements of a circuit to a finite set of parts. The assignment must satisfy the constraints of the selected problem formulation and is evaluated by one or more objective functions. This chapter defines the objects required for that formulation and identifies the assumptions under which the resulting quantities can be compared.

<section id="problem">

## 1. Partitioning instance

A partitioning instance contains a representation of circuit connectivity, a finite target set of parts or devices, resource demands, capacity limits, and a cost model. A solution assigns every eligible circuit element to one part. The meaning of that assignment depends on the semantics of the selected representation.

Let $V$ denote a finite vertex set and $K$ a finite set of parts. A partition is represented by a total assignment $P: V \rightarrow K$. At minimum, each vertex is assigned exactly once. Additional feasibility conditions may constrain resource utilization, legal placement, clock domains, timing, or replication.

<Note title="Modeling convention">

A netlist, a graph, and a hypergraph may represent related connectivity without preserving the same fan-out, timing, placement, or resource information. Every dataset and result must therefore identify its model profile.

</Note>

<section id="model">

## 2. Initial profile: directed red-black hypergraphs

The first data contract represents a circuit by a directed red-black hypergraph. Black vertices represent combinational resources. Red vertices represent state boundaries, typically registers or input/output boundaries. A directed hyperarc has one source and one or more sinks and therefore preserves one-to-many connectivity.

Within this profile, a combinational timing path **starts at a red source boundary and ends at the next red sink boundary**. Every internal vertex is black. Encountering a red vertex terminates the current path because the corresponding register captures state on a clock edge; the following combinational region begins after that boundary.

This profile is used for the initial reference instance and does not constitute a universal representation of circuit partitioning problems. Additional profiles may be introduced when their semantics, conversion losses, provenance, and validation rules are specified.

## 3. Feasibility and objective functions

For each part $k$, let $u_k(P)$ denote the resource utilization induced by partition $P$, and let $C_k$ denote its capacity. The partition is feasible only if $u_k(P) \leq C_k$ for every constrained resource and every part. Objective values are reported separately from feasibility.

The initial convention profile defines three objective families.

### Cut objective

$$
f_c(P) = \sum_{e \in E} w_e\, \mathbf{1}\!\left[\left|\{P(v): v \in e\}\right| > 1\right]
$$

$f_c$ is the sum of the weights of hyperarcs whose incident vertices belong to more than one part. Alternative cut definitions require distinct metric identifiers.

### Topology-aware communication objective

$$
f_{\lambda}(P, T) = \sum_{e \in E} w_e\, d_T\!\left(P(s_e), \{P(v):v\in e\}\right)
$$

$f_{\lambda}$ combines partition $P$ with a target topology $T$. Its interpretation depends on the declared routing or distance rule and is not interchangeable with an unweighted cut metric.

### Timing or path objective

$$
f_p(P) = \max_{\pi \in \Pi} \sum_{v \in \pi} d_v + \sum_{(u,v) \in \pi} d_{uv}(P)
$$

$f_p$ is the maximum cost of a path in the declared path set $\Pi$, using the specified vertex and connection delays. The definition of $\Pi$ and the treatment of state boundaries are part of the model profile.
